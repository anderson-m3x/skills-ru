# Стартовые маршруты

Над полем ввода новой сессии появляется строка кнопок: каждый маршрут — это тип задачи, а не имя скилла. Нажатие подставляет в черновик готовую команду, и первое сообщение сессии сразу начинается со скилла.

## Что видно

Строка показывается только у пустой сессии: пока в ней нет ни одного сообщения и черновик пуст. Как только появляется текст или отправлено первое сообщение, строка исчезает и возвращается, если очистить черновик.

| Кнопка | Команда |
|:--|:--|
| Обсудить идею | `/grill-with-docs` |
| Починить баг | `/diagnosing-bugs` |
| Отревьюить код | `/code-review` |
| Исследовать вопрос | `/research` |
| Триаж issue | `/triage` |
| Прототип | `/prototype` |
| Подобрать скилл | `/ask-matt` |
| Все скиллы | `/` — открывает полный список команд |

Подсказка при наведении объясняет, что делает маршрут. После нажатия курсор переносится в поле ввода, чтобы можно было сразу описать задачу.

## Как устроено

Плагин регистрирует одну запись в слоте `conversation.input.dock` — это слот полноширинных вставок над полем ввода. Он же используется очередью сообщений, поэтому запись плагина имеет собственный `id` и порядок `order: 20`.

Текст интерфейса идёт через сервис локализации под пространством имён `start-routes`: русский и английский словари. Оформление использует только токены темы (`--dsw-alias-label-*`, `--dsw-alias-bg-layer-*`, `--dsw-alias-border-*`), поэтому строка одинаково выглядит в светлой и тёмной палитре.

## Ограничения

- Строка не появляется на холодном старте без выбранной сессии: в этом состоянии слот ещё не объявлен. Она видна у новой (пустой) сессии, то есть сразу после создания сессии или выбора рабочего каталога.
- Фокус в поле ввода ставится поиском по атрибуту `data-composer-seat`, который объявляет сам DSH; это не документированный API, и при смене разметки фокус просто не переедет.
- Список маршрутов задан в `client.js` и не выводится из каталога скиллов: если скилл переименовать, маршрут нужно поправить здесь же. Кнопка «Все скиллы» всегда показывает живой список команд.
- Открытие меню по кнопке «Все скиллы» подставляет `/` в черновик; список раскрывает сам DSH.
