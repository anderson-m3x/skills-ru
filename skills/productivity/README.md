# Productivity

Общие инструменты рабочего процесса, не привязанные к коду.

## Вызываемые пользователем

Доступны только при явном вызове (в DSH: `disable-model-invocation: true` в фронтматтере скилла).

- **[grill-me](./grill-me/SKILL.md)**: Быть безжалостно проинтервьюированным по плану или дизайну, пока не разрешена каждая ветвь дерева дизайна.
- **[handoff](./handoff/SKILL.md)**: Скомпактить текущую беседу в handoff-документ, чтобы другой агент мог продолжить работу.
- **[teach](./teach/SKILL.md)**: Обучить пользователя новому скиллу или концепции за несколько сессий, используя текущий каталог как stateful-рабочее пространство для обучения.
- **[to-questionnaire](./to-questionnaire/SKILL.md)**: Превратить решение, на которое ты не можешь ответить сам, в Markdown-опросник для того единственного, кто может (заполняется асинхронно или вместе на встрече).
- **[wait-what](./wait-what/SKILL.md)**: Запускать в тот момент, когда сообщение не дошло. Агент переизлагает его с недостающим тебе контекстом, простым языком и с использованием словаря из твоего `GLOSSARY.md`.

## Вызываемые моделью

Доступны модели или пользователю (насыщенные фразы-триггеры, чтобы модель могла до них дотянуться).

- **[grilling](./grilling/SKILL.md)**: Безжалостно интервьюировать пользователя по плану, решению или идее, пока не разрешена каждая ветвь дерева дизайна.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: Написание документов для агентов: скиллы, AGENTS.md и любой документ, до которого агент добирается по указателю.
