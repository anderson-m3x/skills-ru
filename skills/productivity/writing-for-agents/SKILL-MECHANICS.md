# Механика скиллов

Специфичная для скиллов ветка [`writing-for-agents`](SKILL.md): что меняется, когда документ — это скилл (фронтматтер, выбор способа вызова и скиллы-маршрутизаторы). Всё остальное о его написании — универсальная справка в `SKILL.md`.

## Способ вызова

Два выбора, торгующие двумя нагрузками:

- **Скилл, вызываемый моделью** (model-invoked), сохраняет `description`, чтобы агент мог запускать его автономно и другие скиллы могли до него добраться. Вы всё ещё можете набрать его имя: вызов моделью всегда _включает_ доступ человека; описание только добавляет обнаружение агентом, никогда не убирает человеческое. Описание — верхнеуровневый контекстный указатель скилла, вынужденный оставаться загруженным всё время: постоянная контекстная нагрузка в обмен на обнаружимость. Скилл, вызываемый моделью, весь контент которого — справка, также одно из пристанищ общей справки: другой скилл может его вызвать, поэтому справка, нужная нескольким скиллам, живёт в одном месте. Механика: опустите `disable-model-invocation` и напишите обращённое к модели описание, несущее ветки-триггеры (правила написания указателей в `SKILL.md` применяются полностью).
- **Скилл, вызываемый пользователем** (user-invoked), вырезает описание из досягаемости агента: только человек, набирающий его имя, может его вызвать, и никакой другой скилл не может. Нулевая контекстная нагрузка, но он тратит когнитивную: вы — индекс, который должен помнить, что он существует. Механика: поставьте `disable-model-invocation: true`; `description` становится обращённым к человеку: однострочное резюме, списки триггеров вырезаны.

Выбирайте вызов моделью только когда агент должен доходить до скилла сам или до него должен доходить другой скилл. Если он всегда запускается только вручную, сделайте его вызываемым пользователем и не платите контекстной нагрузкой.

Общая справка, нужная двум вызываемым пользователем скиллам, не может жить ни в одном из них: без описаний ни один не может запустить другой. Протолкните её в обычный файл вне системы скиллов: внешняя справка, на которую может указать любой скилл.

## Разделение по способу вызова

Разрез по способу вызова (разрез по последовательности живёт в `SKILL.md`): отщепите вызываемый моделью скилл, когда у вас есть отдельное ведущее слово, которое должно запускать его само (слово-триггер, которое вы действительно используете в промптах), или до него должен доходить другой скилл. Вы платите контекстной нагрузкой за новое постоянно загруженное описание, так что независимая досягаемость должна того стоить.

## Скиллы-маршрутизаторы

Когда вызываемых пользователем скиллов становится больше, чем вы можете помнить, накопленную когнитивную нагрузку лечит **скилл-маршрутизатор**: один вызываемый пользователем скилл, который называет остальные и когда к какому обратиться, так что человеку нужно помнить один скилл вместо многих. Он может только намекать, но никогда их не запускает: у вызываемых пользователем скиллов нет описания, поэтому до них не добраться никому, кроме человека.
