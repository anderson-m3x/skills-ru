# Формат RESOURCES.md

`RESOURCES.md` — выверенный набор заслуживающих доверия источников по теме. Знания для объяснений должны черпаться отсюда, а не из параметрических догадок. Мудрость приходит из сообществ, перечисленных здесь.

## Структура

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Правила

- **Только высокое доверие.** Предпочитайте первичные источники, признанных экспертов, рецензируемые работы и сообщества с сильной модерацией. Если ресурс — маркетинг, переодетый в обучение, не включайте его.
- **Аннотируйте каждую запись.** Голая ссылка через три месяца бесполезна. Добавьте строку: что она покрывает и когда к ней обращаться.
- **Группируйте по Knowledge / Wisdom.** Это отражает философию в [SKILL.md](./SKILL.md). Ничего страшного, если ресурс появляется только в одной группе.
- **Явно выявляйте пробелы.** Если для области, нужной миссии, нет хорошего ресурса, напишите раздел `## Gaps` со списком того, чего не хватает. Это направляет будущий поиск.
- **Безжалостно вычищайте.** Ресурс, который оказался неверным, поверхностным или не по миссии, следует удалить, а не закапывать. Лучше пять острых источников, чем тридцать посредственных.
- **Записывайте предпочтения по сообществам.** Если пользователь отказался вступать в сообщества, отметьте это здесь, чтобы будущие сессии не предлагали их снова.
